# AG-Mamba Code

This directory is the source-only part of the reproducibility package and is
intended to be uploaded as a GitHub repository. It contains the AG-Mamba
implementation, baseline implementations, dataset loaders, experiment
drivers, analysis scripts, and the protocol documentation. It deliberately
does not contain raw datasets, experiment logs, checkpoints, or generated
results.

### The full code data and results are at [BaiduDisk](https://pan.baidu.com/s/1TkTwxDx8E47TRmpDGCe2Qg?pwd=agm)

## Layout

```text
agmamba/          AG-Mamba method and configuration
baselines/        comparison implementations
models/           neural network components
utils/            training and evaluation utilities
datasets/         HUST, PU, and PHM2009 loaders
experiments/      single-run and batch experiment entry points
analysis/         result summaries and figure/table generation
paper_experiments/ manuscript-specific manifests and notes
tools/            validation and inventory utilities
docs/             experimental protocol
```

## Installation

```bash
conda create -n agmamba python=3.9 -y
conda activate agmamba
pip install -r requirements.txt
# Optional CUDA SSM acceleration
pip install mamba-ssm==2.2.4 causal-conv1d==1.4.0
```

## Data and external paths

For the packaged local layout, data can be placed in `code/data/`. This
directory is ignored by `.gitignore` and should not be committed to GitHub.
For a clean clone, keep data outside the repository and set these variables:

```bash
export AGM_DATA_ROOT=/path/to/AG-Mamba_reproducibility_package/data
export AGM_RESULTS=/path/to/AG-Mamba_reproducibility_package/results/runtime_logs
export AGM_WEIGHTS=/path/to/AG-Mamba_reproducibility_package/results/checkpoints/runtime
export AGM_HUST_NPZ=/path/to/AG-Mamba_reproducibility_package/data/HUST/hust_x1024.npz
```

`AGM_DATA_ROOT` must contain `HUST`, `PU`, and `PHM2009` directories. The
HUST cache is generated by `python tools/prepare_hust.py`. Run
`python datasets/paths.py` to check all required paths before training.

The data directory is not a Python package dependency: raw data are read by
the dataset loaders, while logs and checkpoints are redirected by
`AGM_RESULTS` and `AGM_WEIGHTS`.

## Main entry points

```bash
python experiments/run_cell.py --method AGMamba --dataset HUST --task T0 --seed 0
python experiments/run_stage.py <stage>
python experiments/nested_alpha_hust.py
python analysis/summary_alpha_sweep.py
```

## Result parsing

Set `AGM_RESULTS` to the result group being analyzed. Each log contains
multiple `tgt_acc:` evaluation points. The manuscript main tables use the
mean of the final five points per unit (`last5`) and then aggregate the five
seeds. Do not substitute peak accuracy or the final single point.

```bash
export AGM_RESULTS=/path/to/AG-Mamba_reproducibility_package/results/main
python analysis/make_all_methods_report.py HUST --readout last5 --out /tmp/hust_report.md
python analysis/make_61_tables.py HUST --out /tmp/hust_tables.md
AGM_SUMMARY_OUT=/tmp/hust_compare.md python analysis/summary_compare.py HUST
```

Probe-specific summaries accept their archived result directory explicitly:

```bash
python analysis/summary_front_ablate.py \
  --dir ../results/ablation_probes/front --out /tmp/front.md
python analysis/summary_align_ablate.py \
  --dir ../results/ablation_probes/align --out /tmp/align.md
python analysis/summary_tau_ssm_ablate.py \
  --dir ../results/ablation_probes/tau --out /tmp/tau.md
```

For α sensitivity, set `AGM_ALPHA_RESULTS` to either
`results/alpha_sensitivity/target_t0_t9` or
`results/alpha_sensitivity/target_t4_t8`, and set `AGM_SUMMARY_OUT` to a
writable output file before running `analysis/summary_alpha_sweep.py`.

Before running a full batch, inspect `docs/PROTOCOL.md`. It records the
training budgets, seeds, readout rules, nested-validation protocol, and the
distinction between confirmatory evaluation and exploratory sensitivity
experiments.
